web-v2 (Backend & Web)

PHP / JS
  • Framework: Laravel ^11.0 + Sanctum ^4.0
  • Runtime: PHP 8.4-FPM + Nginx + Supervisor
  • Frontend Web: Blade + Vue 3.2 + Pinia + Laravel Mix 6
  • Base de Datos: MySQL 8.0 (146 migraciones)
  • Archivos: Spatie MediaLibrary ^11.4 sobre AWS S3
  • Permisos: Spatie Permission ^6.1 (5 roles)
  • Colas & Cron: Worker database en Supervisor. El scheduler de Kernel.php requiere ejecución independiente
  • Deploy: GitHub Actions → AWS ECR → EC2 Docker Swarm

clientes-v2 (Solutoday)

Dart / Flutter
  • Versión: 11.14.0+102 (booking_system_flutter)
  • IDs: com.solutoday2.app (Android/iOS)
  • Estado: MobX (^2.5.0) + 5 Stores + Caché en memoria
  • Persistencia: nb_utils (SharedPreferences)
  • Auth: Email/Pass + Google Sign-In + Apple Sign-In
  • Chat & Push: Firestore + Storage + FCM v1
  • Pagos: 11+ pasarelas + Wallet + Cash/Transacción
  • Extra: 5 dashboards configurables, búsqueda por voz, tracking GPS

proveedor-v2 (Soluexperto)

Dart / Flutter
  • Versión: 11.14.0+95 (handyman_provider_flutter)
  • IDs: com.solutoday2.provider (Android/iOS)
  • Roles: Dual en runtime (provider y handyman)
  • Estado: MobX (^2.5.0) + TimeSlotStore + RolesStore
  • Suscripciones: RevenueCat (purchases_flutter) + API
  • Operación: Catálogo, Slots, Pujas, Banners, Evidencias, Cash
  • Analytics: Syncfusion Flutter Charts
  • Tracking: Emisión de coordenadas GPS a Laravel
